# SentinelAI — Threat Detection Matrix

This matrix documents the threat classifications supported by the SentinelAI hybrid detection engine, detailing required features, detector strategies, machine-readable evidence items, operational limitations, and false-positive mitigation controls.

---

## Threat Matrix

| Threat Category | Required Features | Detector Types | Machine-Readable Evidence | Operational Limitations | False-Positive Mitigation |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **SYN Flood** (`SYN_FLOOD`) | `tcp.syn_count`, `tcp.syn_ack_ratio`, `network.packets_per_second` | `RULE`, `ML` | Observed SYN count, SYN/ACK ratio vs threshold, arrival rate (PPS) | Does not capture multi-source distributed SYN floods without host/subnet aggregation context. | Requires both high SYN count ($\ge 20$) AND high SYN/ACK imbalance ($\ge 5:1$) to avoid flagging busy web servers. |
| **UDP Flood** (`UDP_FLOOD`) | `network.total_packets`, `network.packets_per_second`, `network.bytes_per_second` | `RULE`, `ML` | Total UDP packet count, PPS rate, byte transfer rate (BPS) | Legitimate high-throughput UDP streaming (e.g. QUIC video or WebRTC) may exhibit high packet rates. | Evaluates byte volume, packet volume, and PPS concurrently. Configurable rate thresholds. |
| **Port Scan** (`PORT_SCAN`) | `network.duration_sec`, `network.total_packets`, `tcp.rst_count`, `context.scanned_ports_count` | `RULE`, `ML` | Distinct targeted ports count, short probe connection duration ($< 2.0\text{s}$), TCP reset flag | A single network flow cannot reliably confirm a port scan. Single isolated probes are ignored. | Mandatory requirement for multi-flow host context ($\ge 10$ unique ports) before triggering an alert. |
| **C2 Beaconing** (`C2_BEACONING`) | `timing.jitter_ratio`, `timing.mean_inter_arrival_sec`, `network.total_packets` | `RULE` | Inter-arrival jitter ratio ($< 15\%$), mean heartbeat period interval, packet count | Sophisticated C2 malware with high random sleep jitter ($> 30\%$) bypasses basic periodicity heuristics. | Explicitly excludes standard periodic protocols (NTP port 123). Requires minimum of 6 packets. |
| **DNS DGA** (`DNS_DGA`) | `dns.shannon_entropy`, `dns.digit_ratio`, `dns.query_length`, `dns.is_nxdomain` | `RULE` | Shannon entropy value, digit ratio, total query length, NXDOMAIN status | Content delivery networks (CDNs) and anti-spam services use long hash-based subdomains. | Evaluates NXDOMAIN response flag and requires entropy $> 3.65$ bits/char and digit density $\ge 15\%$. |
| **DNS Tunneling** (`DNS_TUNNELING`) | `dns.query_length`, `dns.subdomain_depth`, `dns.unique_char_ratio` | `RULE` | Total query length ($> 60$ chars), subdomain label depth ($\ge 4$), unique character ratio | High-entropy TXT records or cryptographic lookup queries can generate false positives. | Requires conjunction of extreme query length, multi-tier subdomain depth, and high unique character density. |
| **Suspicious TLS** (`SUSPICIOUS_TLS`) | `tls.tls_version`, `tls.sni_present`, `tls.cipher_suite_count`, `tls.ja3_hash` | `RULE` | Insecure protocol version string, missing SNI flag on port 443, cipher count, JA3 hash | Legacy internal enterprise applications may legitimately use older TLS versions or omit SNI. | Distinguishes deprecated protocol version (MEDIUM) from active blacklisted JA3 signatures (HIGH). |
| **Data Exfiltration** (`DATA_EXFILTRATION`) | `network.forward_bytes`, `network.byte_asymmetry_ratio`, `network.bytes_per_second` | `RULE`, `ML` | Forward byte volume, directional byte asymmetry ratio ($> 0.85$), transfer rate | Cannot verify whether outbound data is sensitive or encrypted intellectual property without payload inspection. | Labeled as suspicious bulk transfer; requires both massive outbound bytes ($\ge 250\text{KB}$) and severe directional asymmetry. |
| **Behavioral Anomaly** (`BEHAVIORAL_ANOMALY`) | All `network.*` and `timing.*` numerical features | `STATISTICAL` | Deviating feature names, observed values, baseline $\mu$, baseline $\sigma$, Z-scores | Dependent on baseline quality; baseline poisoning possible if initial profiling includes attacks. | High statistical threshold ($|z| \ge 3.5$); adaptive baseline update function (`update_baseline`). |
| **Benign Traffic** (`BENIGN`) | All features | `ENSEMBLE` | None (normal operational traffic profile) | N/A | Default state whenever detector signals fall below minimum consensus confidence ($< 0.50$). |
